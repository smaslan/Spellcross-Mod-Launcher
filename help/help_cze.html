Spellcross - MOD builder/launcher

   Spellcross Mod Launcher vznikl za účelem usnadnění modifikací hry protože postupovat stylem dearchivace-editace-archivace každého jednotlivého archivu hry je poněkud nepohodlné zvláště pokud mám rozpracovaných více různých modů. Tato utilitka je schopná, podle zadání v definičním souboru modu, "namixovat" nové herní datové archivy *.FS a *.FSU a případně je automaticky prohodit s původními archivy nainstalované hry i s těmi na CD (pokud je CD emulováno ze složky, namísto z ISO). Následně spustí hro a po jejím ukončení je zase vrátí zpět, aby bylo možné spustit původní hru nebo jiný mod. Tento nástroj lze používat samozřejmě i ke spouštění nemodifikované hry přes DOSbox. Program zároveň obsahuje i nástroje na zálohování uložených her.

Varování

   Nástroj z principu věci přesouvá, kopíruje a někdy maže datové soubory hry. Měl by být sice bezpečný a každá potenciálně nebezpečná operace vyžaduje potvrzení uživatele, ale je to zcela bez záruky. Rozhodně doporučuji udělat si před použitím nástroje zálohu všech souborů hry i uložených her!


1 - Základní nastavení

   Všechna hlavní nastavení lze provést na hlavním panelu. Předně je třeba nastavit cestu k instalaci hry Spellcross installation folder např. "C:/hry/SPELCROS". Dále je třeba nastavit cestu ke kopii CD hry Spellcross CD path. Sice lze nastavit i cestu k namontovanému ISO, ale ISO image pochopitelně nelze modifikovat, takže doporučuji udělat kopii např. do "C:/hry/SPELLCD". Pokud máte ve složce hry několik EXE souborů, např. různé verze patchů hry, můžete si vybrat cílový EXE pro spuštění Spellcross executable. Dále zvolte písmeno jednotky Virtual CD drive letter kam bude namontováno CD hry. Toto nastavení platí jak pro DOSbox, tak i pro Win32 režim. Pokud hry budete spouštět přes DOSbox, pak je třeba také zadat cestu k instalaci DOSboxu DOSbox path. Dále zvolte metodu spuštění hry Run mode. Nástroj byl původně vyvinut v době 32bit WinXP, kde se daly 16bitové DOSové aplikace provozovat nativně přes integrovaný emulátor NTDVM, takže obsahuje možnost spustit nativně "Win32". Toto nastavení je ovšem dnes již trochu mimo a aplikace ani není kompilovaná pro 32bit systém. Ale teoreticky by to mohlo jít spustit ve virtuálním stroji. Každopádně dnes je jediná rozumná metoda režim "DOSbox". Pro režim "DOSbox" lze volitelně vypnout "autoexec.bat" a nastavit spouštění ve fullscreen režimu. Další nastavení je cesta k modu Mod path. Pro spouštění modu lze eventuálně vypnout Allow CD mod, pokud by cesta k CD hry vedla na namontované ISO, které pochopitelně nelze přepisovat. Poslední volba je Move SAVE games. Pokud je vybráno, vytvoří Spellcross Mod Launcher po prvním hraní modu kopii uložených pozic do složky modu "save". Při dalším spuštění modu přesune tyto uložené pozice do herní složky "SAVE" (a pochopitelně zálohuje původní pozice v "SAVE") a po skončení hraní je zase přesune zpět do složky modu a obnoví původní "SAVE". Takto lze mít nezávislé uložené pozice pro každý mod i originální hru a nepletou se dohromady, protože jsou nekompatibilní a hra při načtení většinou padne.



2 - Instalace modu

   Mody netřeba nijak složitě instalovat nebo nastavovat. Stačí stáhnout a někam rozbalit. Zde ovšem upozorňuji, že je vhodné umístit mod na stejnou jednotku, jako je instalace hry, tedy např. pokud je hra na "C:/HRY/SPELCROS", tak někam na jednotku "C:/". Takto je operace prohození originálních datových souborů hry za modifikované pouze otázka přepisu alokačních tabulce souborového systému, ale nedochází k fyzické kopii dat. V opačném případě by pro každé spuštěné došlo k zápisu až 500 MB za což vám váš SSD disk nepoděkuje. Spellcross Mod Launcher je navíc dále optimalizován pro šetření SSD tak, aby negeneroval modifikované soubory, pokud je jejich obsah shodný s originálním mi a také nepřepisuje žádné soubory, pokud se nezmění. Pár modů lze sáhnout zde: https://spellcross.kvalitne.cz/mod/spell_mod_builder.html.

3 - Spouštění hry a modů

   Pro spouštění hry nebo modů stačí použít tlačítka Run Original a pro modifikovanou verzi Run Mod. V případě modifikované verze hry nástroj před spuštěním automaticky vygeneruje modifikované datové archivy, nahradí jimi archivy hry a po skončení je zase vrátí zpět.

4 - Pokročilé operace

   Mimo základního spouštění umožňuje pár další operací. V menu Setup lze spustit "SETUP.BAT" hry pro nastavení zvuku. Dále lze editovat konfigurační soubor Spellcrossu a DOSboxu. V menu Mod lze vybrat Build mod. Tato funkce sestaví datové archivy modu. Volba Force rebuild mod sestaví soubory modu a vynutí zápis na disk i pokud se data proti minulému sestavení nezmění. Volba Build and swap sestaví soubory modu a prohodí je s archivy hry. V tomto stavu zůstanou až do provedení operace Restore mod. Operace Restore mod vrátí soubory modu zpět do složky modu a obnoví původní data hry. Tato funkce je volána automaticky před každou operací, aby se zajistil konzistentní stav dat hry. Nástroj uchovává stav modifikaci v konfiguračním souboru "mod_state.ini", takže by měl být schopen obnovit stav při pádu hry nebo sytému.
   Ve velmi nepravděpodobném případě, kdy by došlo k pádu systému v mezičase mezi přesuny dat a zápisem do "mod_state.ini" by operace Restore mod mohla opakovaně selhávat. V takovém případě lze použít operaci Cleanup mod, která vymaže obsah stavového souboru "mod_state.ini". To je ovšem poslední možnost a téměř jistě povede k nekonzistentním souborům hry a bude pravděpodobně třeba je ručně obnovit ze zálohy. Před touto operací je vhodné se ujistit, že neselhává např. z důvodu prohlížení obsahu některé složky nebo souboru, který má být přesouván (file sharing violation).
   V menu Run lze zvolit Build launch files, což vygeneruje spouštěcí BAT soubory hry. Ty jsou generovány automaticky při spouštění přes Run Original a Run Mod.

5 - Správa uložených pozic

   Jak bylo stručně zmíněno výše, je k dispozici volba Move SAVE games. Ta zajistí, že nástroj po skončení hradní modifikované verze hry přesune uložené pozice do podsložky "save" ve složce modu. Při dalším spuštění je zase přesune zpět do herní složky "SAVE". Díky tomu lze mít několik vzájemně nekolidujících sad uložených pozic pro jednotlivé mody i pro originální hru. Nástroj po výberu modu automaticky nastaví Move SAVE games, pokud ve složce modu najde uložené pozice. Díky této volbě jsou v nástroji vždy všechny operace s uloženými pozicemi dvojmo: Jedny pro originální hru, které pracují se složkou "SAVE" a druhé pro modifikovanou verzi, které pracují s pozicemi v posložce "save" modu.
   Další funkcí nástroje je možnost rychlé zálohy a obnovení dočasné pozice hry ve složce "SAVE/WORKDIR". To je užitečná funkce v misích, kde zničení kritické jednotky ukončí misi bez možnosti nahrání (typicky doprava konvoje). Zde lze postupovat takto: Opustit misi s uložením pozice; ukončit hru; v nástroji zvolit Backup WORKDIR; znovu spustit hru; v případě selhání opět ukončit hru; zvolit Restore WORKDIR a znovu spustit hru a pokračovat v misi. Je to v podstatě uložená pozice navíc. Je to tak trochu podvádění, ale asi lepší, než to hrát celé znovu... Levá tlačítka jsou pro originální hry, pravá pro modifikovanou, pokud je použita volba Move SAVE games.

   Poslední funkcí v menu Savegame je Manage SAVEs. To spustí jednoduchého správce uložených pozic ve kterém lze vytvářet a obnovovat zálohy celé sady uložených pozic buďto ze složky hry "SAVE" nebo lokální uložené pozice ve složce modu "save". Uložené pozice lze obnovovat i jednotlivě. Operace obnovení pochopitelně přepisuje stávající uložené pozice, ale nástroj před každou operací vypíše přesný popis provedených změn, takže doporučuji pečlivě přečíst!

6 - Editor uložených pozic

   V menu Savegame lze spustit Savegame editor. Jedná se o těžce experimentální nástroj pro prohlížení a editaci souboru "big_map.sav", který je jádrem každé uložené pozice Spellcrossu (složky v SAVE). Lze otevřít buďto jednu z nabízených uložených pozic nebo přímo soubor "big_map.sav". Podařilo se mi dešifrovat význam většiny jeho položek, ale stále ještě nějaké neznámé zbývají. Editovat lze sice libovolné položky načtené v panelech editoru, ale ne všechny se uloží. Každopádně před uložením jakýchkoliv změn si udělejte zálohu! Není to plně odladěné.
   Po otevření souboru lze vybrat jednotlivé skupiny nastavení. List Research umožňuje editovat stav výzkumu a vlastnosti vylepšení. To se může hodit, protože výzkum je sice definován v DEF souborech v COMMON.FS, ale hra si vytvoří binární kopii do "big_map.sav" a změny v DEF ignoruje, takže je třeba je provádět zde. Další list Units umožňuje řazení, přejmenování a editaci jednotek hráče. Zejména řazení je užitečné, protože Spellcross bohužel mícha dohromady stále jednotky a posily. Při přechodu na další úroveň odstraní posily a v seznamu zůstanou mezery. Do těch pak umisťuje nové jednotky, takže se to ve hře jeví jako by je řadil náhodně. Zde lze mezery odstranit a případně jednotky ručně přesouvat. V dalším listu Commanders lze editovat velitele a také je přejmenovat. Editor automaticky přiřadí jméno velitele ze seznamu, pokud se bugne (hra někdy sama vymaže jméno velitele, ale všechny jeho parametry zachová). V listu Hierarchy lze sestavit hierarchii velení. To se hodí, když je třeba pořešit známý bug s mizejícími jednotkami a veliteli ve hře. Použití je identické s hrou. V listu Big Map lze editovat vlastnosti území v rámci úrovně hry. To se hodí zejména k odbugnutí některých území, když vám je napadne OS (úroveň 9 - klíče k pohoří). Zde upozorňuji, že může být nutné změnit status i okolních území, aby na ně bylo lze útočit. Inspirujte se některým funkčním savegame. Poslední záložka Level umožňuje editaci některých globálních parametrů jako statistiky, peníze a apod.


6 - Vytváření modů

   Celý koncept modifikací spočívá v maximálním využití původních dat hry. Nebylo by praktické pro každý mod distribuovat všechna data hry. Navíc by to mohlo být v rozporu s copyrightem. Proto je koncept postaven tak, že se modifikace generuje runtime při spuštění hry z původních souborů a mod obsahuje pouze nové nebo modifikované soubory. Tato kapitola stručně popíše strukturu modu. Příklad složky modu může být následující: 

./data/common/M01_01A.DEF
./data/common/RESEARCH.DEF
./data/common/...
./data/units/MAMUT/000
./data/units/MAMUT/001
./data/units/MAMUT/...
./info/info.html
./info/...
./make/common.fs
./make/units.fsu
./config.def

   Struktura modu je definována v souboru "*.def". Jeho formát je ve stylu C++ tříd. Obsahuje několik sekcí. První a povinnou sekci je "class PATH", kde jsou definovány cesty ke zdrojům souborů hry. Příklad: 

class PATH
{
    // --- REQUIRED ITEMS (reserved names) ---
    // make folder, relative path to folder to store output archives
    MAKE=make;

    // --- OPTIONAL ITEMS ---        
    // links to original game data files
    COMMON=%SPELL%\DATA\COMMON.FS;
    UNITS=%SPELL%\DATA\UNITS.FSU;
    
    // folder with this mod data
    DMOD=data;

    // the mod data folders
    MOD_COMMON=%DMOD%\COMMON;
    MOD_UNITS=%DMOD%\UNITS;
}

Proměnná "MAKE" je povinná a určuje cílovou složku, kam nástroj generuje modifikované soubory. V příkladu to bude podsložka "make" ve složce modu. Všechny ostatní zde definované proměnné jsou volitelné. Každá může obsahovat odkazy na již definované proměnné ve formátu %název_proměnné%. Nástroj navíc obsahuje tři předem definované proměnné: %SPELL%, %SPELLCD% a %SPELLANY%. %SPELL% a %SPELLCD% odkazují na složky vybrané v nastavení nástroje Spellcross installation folder a Spellcross CD path. Proměnná %SPELLANY% automaticky volí mez %SPELL% a %SPELLCD%, což je vhodné, protože různé verze Spellcrossu mají datové soubory různě rozdělení mezi CD a instalační složkou hry.
   Poznámka: Původní verze tohoto nástroje navíc obsahovala ještě sekci "class SRC", kde bylo možné definovat další cesty a je podporována i v této verzi, ale jednodušší je vše definovat v sekci "class PATH".
   V přikladu výše jsou definovány cesty "COMMON" a "UNITS", které odkazují na originální datové archivy hry. Proměnná "DMOD" odkazuje na podsložky "data" modu. Zbylé proměnné "MOD_COMMON" a "MOD_UNITS" odkazují na konkrétní podložky s datovými soubory modu.
   V "*.def" souboru následují sekce pro každý datový archiv hry, který má být modifikován. Příklad pro archiv "COMMON.FS" je následující: 

class COMMON.FS
{
    replace=1;                      // by default overwrite previous data by each add() command
    optional=0;                     // optional flag (default 0: generate error if source not found)
    add(%COMMON%);                  // add all data from original game archive COMMON.FS
    add(%MOD_COMMON%,M01_01A.DEF);  // add specific file from mod "data/COMMON" folder
    add(%MOD_COMMON%,*.CUR);        // add wildcard key matching files from mod "data/COMMON" folder
    add(%MOD_COMMON%);              // add all files from mod "data/COMMON" folder
}

   Přepínač "replace=1" znamená, že každý další příkaz "add()" přepíše soubory přidané předchozími příkazy. "replace=0" znamená, že jsou přidány pouze nové soubory a již existující jsou přeskočeny. Tato volba může být provedena i jednotlivě pro každý příkaz "add()". Varianty parametrů příkazu "add()":

add(zdroj);               // přidá všechny soubory ze "zdroj"
add(mód,zdroj);           // viz výše, "mód" může být NEW (přidá pouze nové soubory) nebo ALL (přepisuje existující)
add(zdroj,wildcard);      // přidá soubory odpovídající klíči ve formátu "wildcard" (např *.LZ nebo LEVEL_??.DEF)
add(mód,zdroj,wildcard);  // viz výše s definicí režimu "mód"

Přepínač "optional=1" označí archiv jako volitený, takže nástroj negeneruje chybu pokud "zdroj" nebude nalezen. Defaultní hodnota je "optional=0", tj. "zdroj" mustí existovat.
   Všechny datové archivy hry "*.FS" jsou identické. Výjimkou je pouze "UNITS.FSU". Ten obsahuje sprity jednotek a jako jediný je členěn do podsložek. Každá podsložka reprezentuje jednu jednotku a musí mít název do délky 5 znaků. Jednotlivé podsložky pak obsahuji LZ komprimované sprity s názvy délky 3 znaky. Ve zdrojových složkách modu tedy musí být odkazované data organizovány v podložkách, viz příklad "data/units/MAMUT". Příklad sekce pro "UNITS.FSU": 

class UNITS.FSU
{
    add(%UNITS%);              // add all data from original game archive COMMON.FSU
    add(%MOD_UNITS%,MAMUT);    // add unit data from "data/UNITS" folder    
}

   Každý mod může mít jednoduchou dokumentaci v HTML formátu v podsložce "info" v souboru "info.html". Tu lze z nástroje zobrazit pomocí Show mod info
.    Pro zjednodušení vytváření nového modu lze využít template distribuovaný s tímto nástrojem, který je umístěn ve pod-složce nástroje "mod_template". Je to jednoduchá kostra modu, která načte všechna data originální hry a následně doplní nebo přepíše originální soubory daty ze složek modu, takže stačí do nich nahrát cokoliv má být přidáno/modifikováno.
